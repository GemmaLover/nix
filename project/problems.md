## [P-1] asusd-user падает с SIGABRT (Rust panic)

**Дата:** 2026-09-24
**Статус:** Решено
**Устройство:** z13

**Описание:** После применения конфига пользовательский сервис `asusd-user.service` постоянно падал с `SIGABRT`. Всплывали уведомления «service crash». Логи показывали Rust panic в `async_executor`.

**Причина:** В `asus-tools.nix` мы создавали оба сервиса (`asusd` и `asusd-user`) вручную, вместо использования встроенного модуля NixOS `services.asusd`. Пользовательский сервис `asusd-user` нужен только для AniMe Matrix (матрица на крышке G14/G16), которой на Z13 нет. При отсутствии AniMe-устройства он паникует.

**Решение:**
1. Заменили ручное создание сервисов на `services.asusd.enable = true` — это официальный модуль NixOS, корректно настраивающий D-Bus и зависимости.
2. Не включали `services.asusd.enableUserService` — пользовательский сервис не нужен для Z13.
3. Добавили `systemd.tmpfiles.rules = [ "d /etc/asusd 0755 root root -" ]` — `asusd` требует эту директорию для конфигов.

**Файл:** `devices/z13/specific/asus-tools.nix`

## [P-2] Sublime Text требует небезопасный openssl-1.1.1w

**Дата:** 2026-09-24
**Статус:** Решено (пакет удалён)
**Устройство:** z13

**Описание:** `nixos-rebuild` падал с ошибкой `Refusing to evaluate package 'openssl-1.1.1w' ... because it is marked as insecure`.

**Причина:** Пакет `sublime4` требует OpenSSL 1.1.1w, поддержка которого прекращена в 2023 году, и который в nixpkgs помечен как небезопасный.

**Решение:** Удалён `sublime4` из `base/tools/base.nix`. Рассмотреть альтернативы: `vscode`, `neovim`, `kate` (уже установлен через KDE).

**Альтернатива (не использовалась):** `nixpkgs.config.permittedInsecurePackages = [ "openssl-1.1.1w" ]` — снижает безопасность.

## [P-3] `sublimetext4` не существует как атрибут nixpkgs

**Дата:** 2026-09-24
**Статус:** Решено
**Устройство:** z13

**Описание:** Попытка заменить `sublime4` на `sublimetext4` привела к ошибке `undefined variable 'sublimetext4'`.

**Причина:** `sublimetext4` — это `pname` пакета, а не имя атрибута. В nixpkgs атрибут называется `sublime4`.

**Решение:** Учитывать это при поиске пакетов — смотреть атрибут, а не `pname`.

## [P-4] Git tree is dirty — Flake видит только закоммиченные файлы

**Дата:** 2026-09-24
**Статус:** Решено
**Устройство:** любое

**Описание:** При добавлении новых `.nix`-файлов `nixos-rebuild` не видел их, выдавал `error: file '...' was not found in the Nix store`.

**Причина:** Flake при сборке копирует в `/nix/store` только те файлы, которые отслеживаются Git. `git add` без `git commit` не помогает — файл остаётся в staging area и Flake его не подхватывает.

**Решение:** Всегда `git add . && git commit -m "..."` перед `nixos-rebuild`. Предупреждение `Git tree is dirty` — сигнал, что есть незакоммиченные изменения.
